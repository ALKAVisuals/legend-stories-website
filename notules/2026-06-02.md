## Besproken onderwerpen

### 1. Checkout flow & adresvalidatie
- Besproken dat de checkout modal alleen op `music-pure-confidence.html` stond
- Besloten om de modal HTML naar ALLE detail pages en shop page te kopiëren
- Uitgevoerd: modal toegevoegd aan alle 26 pagina's en gepushed

### 2. Google Places Autocomplete
- K wilde dat adressen gevalideerd worden via Google Places
- Besproken kosten: $200/maand gratis krediet bij Google Cloud (~80.000 autocomplete calls)
- K heeft Google Cloud API key geleverd
- Geïmplementeerd:
  - Autocomplete op straat+nummer veld
  - Automatisch invullen van postcode, stad, land bij adres-selectie
  - Land dropdown wordt uitgeschakeld na validatie (voorkomt misbruik verzendkosten)
  - Verzendkosten altijd gebaseerd op gevalideerd adres land, niet dropdown
  - "Continue to payment" werkt alleen als adres uit Places komt
  - Email format validatie toegevoegd

### 3. Misbruik verzendkosten
- K vroeg of gebruikers niet een ander land kunnen kiezen voor goedkopere verzending
- Antwoord: land wordt automatisch ingevuld door Places en is daarna disabled
- Verzendkosten worden berekend op basis van het gevalideerde adres land
- Gebruiker kan alleen een ander land krijgen door een ander adres te selecteren

### 4. API Key beveiliging
- K deelde API key in chat
- OWL waarschroeide: key moet geroteerd worden omdat deze in chat history staat
- Key is zichtbaar in frontend JS (niet te vermijden)
- Aanbeveling: key beperken tot `https://alkavisuals.github.io/*` en alleen Places API
